# 截图

README 首屏用的是这两张，都是真实页面截图，不是示意图。

| 文件 | 内容 |
| --- | --- |
| `home.png` | 空状态：一句需求的输入框 + 9 个场景模板 |
| `result.png` | 「帮我写个周报」的诊断结果：18 分 D 级、五维评分、缺口清单与三版改写 |

## 怎么重新生成

界面改了要更新截图时：

1. `mvn spring-boot:run`，打开 <http://localhost:8080>；
2. 浏览器宽度调到 1440（F12 设备工具栏可固定）；
3. 首页直接截；结果页输入「帮我写个周报」→ 点「诊断并优化」后截整页；
4. 存成同名文件覆盖即可。

这两张图是用无头 Edge + Chrome DevTools Protocol 驱动真实页面自动截的
（导航 → 执行一次点击 → `Page.captureScreenshot`），所以结果页的数字就是接口真实返回值，没手改过。

截图约定：

- 视口宽 1440，整页截图（`captureBeyondViewport`），不要带浏览器地址栏；
- PNG，单张控制在 300KB 以内（`.gitattributes` 已把 png 标记为二进制）；
- 结果页必须是真实接口输出，不要手改数字。

## 可选：换成 GIF

用 ScreenToGif 录一段 15 秒操作（输入 → 诊断 → 结果 → 复制），
输出 `demo.gif` 控制在 3MB 内，替换 README 顶部两张静图，观感更好。
