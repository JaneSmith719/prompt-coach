# v1.2.1 手动验收清单

自动化测试覆盖了后端行为；下面这些交互/浏览器相关项需要在发布前手动走一遍。

## 准备

```bash
mvn -DskipTests package
java -jar target/prompt-coach-1.2.1.jar
```

浏览器打开 <http://localhost:8080>，建议同时开一个隐身窗口做会话隔离测试。

## 清单

### 1. 零 Key 主流程

- [ ] 不配置 `AI_API_KEY`，输入「帮我写个周报」并诊断。
- [ ] 看到分数、五维评分、缺口、提示词、建议；结果区显示「本地规则引擎」。
- [ ] 结果区第一个 tab 是「整句版」，内容是一段完整句子，没有 `# 角色`、`# 任务` 标题，也没有 `『待补充』`；点「复制」后能直接粘给 AI。
- [ ] 把「整句版」粘到输入框再诊断：分数可能变高，因为通用要求已经补齐了角色/约束/格式，但不会伪造你的真实背景。
- [ ] 勾选「大模型增强」后诊断，报告出现「没有配置 AI_API_KEY」提示，仍然有完整结果。

### 2. 90+ 样例

- [ ] 首页出现「90+ 样例」一行：周报、代码审查、论文润色三个 chip。
- [ ] 点「周报 · 90+」：输入框填入完整需求，侧栏出现「已套用：周报总结」。
- [ ] 直接诊断：分数为 100、等级 S，五个维度全满。
- [ ] 同样验证「代码审查 · 90+」「论文润色 · 90+」，都应该是 100 分。
- [ ] 把输入框里的示例改短，再诊断：分数明显下降，证明样例不是写死的展示数据。

### 3. 模板骨架

- [ ] 点击侧栏「周报总结」：输入框填入示例，出现「已套用：周报总结 ×」chip。
- [ ] 诊断后结果区出现「模板：周报总结」chip 和「模板提示」三列。
- [ ] tabs 里出现「模板骨架版」，内容含「【本周记录】」「【本周目标】」「下周计划」。
- [ ] 点 chip 上的 × 取消模板；再诊断，tabs 回到 4 个版本。
- [ ] 手工把 `templateId` 改成不存在的值发请求，返回 200 + 「不存在」提示，不报 400。

### 4. 收藏与恢复

- [ ] 诊断后点「收藏」，按钮变成「已收藏」，侧栏计数 +1。
- [ ] 刷新页面：收藏仍在（`localStorage` 的 `promptcoach.favorites.v1`）。
- [ ] 点收藏项：立即恢复报告、输入框和模板 chip，不重新请求 `/api/coach`。
- [ ] 同一需求再收藏：提示「已更新收藏」，不产生重复项。
- [ ] 删除单条、清空全部（有 confirm）。
- [ ] 最多 50 条；第 51 条会淘汰最旧一条。

### 5. Markdown 导出

- [ ] 点「导出 Markdown」，下载 `promptcoach-report-YYYYMMDD-HHmm.md`。
- [ ] 文件里有原始需求、评分表、五维评分、推荐提示词、其他版本、建议、下一步。
- [ ] 提示词里含连续反引号时，导出的围栏仍然合法（用 Markdown 预览器检查）。
- [ ] 「收藏夹 → 导出」生成全部收藏的合并文件。

### 6. 分享链接

- [ ] 复制分享链接，应包含 `?q=…`；套用模板后应包含 `&t=weekly-report`。
- [ ] 新隐身窗口打开链接：自动套用模板并自动诊断。
- [ ] 把 `q` 改成乱码：页面提示分享链接损坏，不白屏。

### 7. 会话隔离

- [ ] 普通窗口诊断 2 条；隐身窗口打开，历史中看不到前者的记录。
- [ ] 隐身窗口诊断 1 条；普通窗口点「清空」，隐身窗口的历史仍在。
- [ ] 清 Cookie 后刷新：历史为空，诊断仍可用。

### 8. 增强配额

```powershell
$env:AI_API_KEY="sk-xxx"
$env:COACH_ENHANCE_PER_SESSION_PER_HOUR="1"
java -jar target/prompt-coach-1.2.1.jar
```

- [ ] 第一次勾选增强：模式为「大模型增强」。
- [ ] 同一会话第二次勾选增强：降级为「本地规则引擎」，notice 含「上限」。
- [ ] 换个隐身窗口（新会话）第一次增强仍可用（如果全站配额未到）。
- [ ] 把 `COACH_ENHANCE_GLOBAL_PER_HOUR=0` 后，全站限制关闭。

### 9. localStorage 异常

- [ ] DevTools → Application → Storage 禁用/清空，收藏仍能在当前页面使用，并提示「刷新后会丢失」。
- [ ] 手动写入损坏 JSON 到 `promptcoach.favorites.v1`，刷新：页面正常，收藏重置并提示。
- [ ] 浏览器隐私模式：页面不崩，诊断/导出仍可用。

### 10. 响应式与可访问性

- [ ] 390px 宽度：结果区按钮换行、模板 chip 不溢出、侧栏正常下沉。
- [ ] Tab 键可依次到达模板、收藏、导出、分享、复制按钮。
- [ ] 错误提示、notice、toast 有 `role="status"`/`aria-live`。
